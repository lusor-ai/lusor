This app shows and saves times on the 24-hour clock. A task time "at Nh" is N:00 on that clock: "at 2h" is 02:00, "at 14h" is 14:00. It is never PM unless the task itself says PM. Before opening a time picker, write the start and end times as HH:MM taken from the task's own words, and compare the saved event against the task's words, not against your own plan.

To set a time, switch the picker to keyboard mode, type the hour field and the minute field separately, and read both fields before OK.
