For an ordered track, use Menu → Plan a route → Create new route.
Like any map app, OsmAnd’s view can be moved, widened or narrowed, and its search only covers an area around the current map centre: when the places may not be near that centre, first search and select the region or country they are in (e.g. a country name) to centre the map, then search each place in order by name; wait for the search to settle and read the result list before concluding anything. Never guess coordinates or download maps, and never infer missing maps from a size/grouping row. Select its matching place result, open “SHOW … ON THE MAP” if offered, then use Back to close the place card and return to the planner, and press the planner’s Add button without panning or tapping the map; Add uses the map centre set by the place selection, not the place menu’s Add Favorite action. Never tap the map to close a card: in the planner a map tap adds a stray point, and an Add after undoing it lands away from the place. If a point lands wrong or a stray point appears, undo it, then repeat the search and selection for that place before pressing Add again.
Use Options → Save as new track in Tracks, then reopen and check the path’s points in order; Map markers and standalone waypoints do not extend the track.
