# Security

Please report security issues privately to **support@lusor.ai** with
"Security" in the subject, not in a public issue or pull request. Include what
you found, how to reproduce it, and the version or commit you tested.

You'll get an acknowledgement and updates until the issue is fixed. Please
allow a reasonable chance to fix it before you disclose it publicly.

This covers the code in this repository. Issues in the hosted Lusor service
at lusor.ai go to the same address.
