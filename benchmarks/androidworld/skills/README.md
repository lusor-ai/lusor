# AndroidWorld app skills

These six skills (Markor, Broccoli, Simple Calendar, Tasks, OsmAnd and Camera)
were written for the test apps of the
[AndroidWorld](https://github.com/google-research/android_world) benchmark.
They were in Lusor's skill catalog during Lusor's 9 November 2026 AndroidWorld run,
and they are kept here as benchmark evidence.

Lusor's agent doesn't load this folder. Some rules here follow how the
benchmark phrases and grades its tasks rather than what an everyday user would
want. For example, Markor notes are saved without a file extension unless the
task names one, and the Camera skill covers the emulator's AOSP Camera2 app,
not the camera apps on most phones. They are not general-purpose skills.

To run AndroidWorld with the same skills, give these files to the agent as
skills for that run.
