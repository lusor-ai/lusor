# Unverified app skills

Skills from the community, recorded skills and drafts live here until they are
reviewed and verified on a real phone. Lusor's agent does not load anything in
this folder. Use these skills at your own judgement.

Each skill uses the same format as [`../skills/`](../skills/README.md): one
folder per app, with a `SKILL.md` file starting with `name`, `description`,
`keywords`, `platform` and `app_package`.

## Contributing a skill

1. Add `skills-unverified/<app>/SKILL.md`. Keep it to navigation and app use,
   and leave out personal data, credentials and account names.
2. In the pull request, describe the tasks you used it for, and the phone, OS
   version and app version you tested on.
3. The skill is reviewed, run on a real phone, and moved to `skills/` with a
   `verification.json` once it passes.

See [CONTRIBUTING.md](../CONTRIBUTING.md) for how pull requests reach this
repository.
